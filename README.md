# True Cosmic Scale: data

The public data behind the [True Cosmic Scale](https://truecosmicscale.com) YouTube
channel ([@TrueCosmicScale](https://youtube.com/@TrueCosmicScale)). Every number shown
on screen comes from a table in this repository, and every row says where it came from.

One folder per video, named after the video's title:

| Folder | Video |
|---|---|
| [`every-moon-in-the-solar-system-ranked/`](every-moon-in-the-solar-system-ranked/) | Every Moon in the Solar System, Ranked by How Strange It Is |

The tables, rubric and text in this repository are licensed under

share and adapt them, including commercially, if you give credit, for example:

The licence covers our tables and wording. The facts in them come from the sources
listed in each row (NASA, JPL, peer-reviewed papers); those sources keep their own
terms. No images or video are stored here.

## Corrections

Think we got a flag wrong? Open an issue with the row, the flag and your source. If the
source holds up we change the row, re-run the ranking and say so in the video's pinned
comment. Flags change only with a cited source.
